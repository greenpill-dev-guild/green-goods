# Admin fonts

Plus Jakarta Sans v12 is the same variable typeface previously served by Google
Fonts. The Latin and extended-Latin WOFF2 subsets were retrieved on 2026-10-21.
Latin covers English, Spanish, and Portuguese; extended Latin remains available
for names and other content.

The font faces and critical Latin preload live in `packages/admin/index.html`.
Keep the 400–700 weight range when replacing the files. The SIL Open Font License
is in `jakarta-OFL.txt`.

Sources: [Google Fonts stylesheet](https://fonts.googleapis.com/css2?family=Plus+Jakarta+Sans:wght@400..700&display=swap)
and [license](https://github.com/google/fonts/blob/main/ofl/plusjakartasans/OFL.txt).
