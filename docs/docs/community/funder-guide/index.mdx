# Funder Guide

Choose the path that matches your intent:

- [Donate](/community/funder-guide/donating-to-a-garden) for direct support through the Garden's current donation destination.
- [Endow](/community/funder-guide/funding-a-garden) to place principal in a Garden Vault whose configured yield can support the Garden.
- [Remove an Endowment](/community/funder-guide/withdraw-from-a-vault) to withdraw principal from an active position.

Before signing, confirm the Garden, network, asset, amount, and destination. Afterward, inspect the transaction state before retrying; a delayed indexed view is not proof that the transaction failed.
