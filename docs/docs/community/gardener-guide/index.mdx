# Gardener Guide

Use the same Green Goods account throughout this flow so your Garden roles, drafts, and Work history stay connected.

1. [Join a Garden](/community/gardener-guide/joining-a-garden) and confirm it appears in your app.
2. [Submit Work](/community/gardener-guide/uploading-your-work) against the Action that matches what you did.
3. Use [Recovery and Sync](/community/gardener-guide/recovery-and-sync) when a draft or queued item needs attention.
4. [Track Status](/community/gardener-guide/track-status-and-attestations) after the submission reaches the steward queue.

If a steward asks for changes, read the feedback, correct the evidence, and submit against the same Garden and Action.
