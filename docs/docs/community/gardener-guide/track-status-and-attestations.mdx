# Track Status and Attestations

<StatusBadge status="Live" />

## Status meanings

- **Pending:** Waiting for steward review.
- **Approved:** Work validated; approval attestation exists.
- **Rejected:** Work requires correction and resubmission.
- **Uploading/Queued:** Submission is still syncing.

## Attestation verification workflow

1. Open approved work details.
2. Copy/select attestation UID and chain.
3. Open the matching network in the official EAS explorer and search for that UID.
4. Confirm approval linkage and timestamps.

Do not copy an explorer URL from an old guide. Use the chain shown on the work record, then choose that network from the official [EAS explorer](https://easscan.org/).
