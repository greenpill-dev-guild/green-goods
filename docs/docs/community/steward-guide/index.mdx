## What this helps you do

This is the core steward path. Use it to create a garden, make an assessment, review incoming work, and mint an impact certificate when the evidence is ready.

The key permission boundary is simple: owners, stewards, and evaluators can make assessments; only owners and stewards approve or reject work.

Day to day the split is simple too: gardeners document work in the [Green Goods app](https://greengoods.app), and you review and approve it here in the [admin dashboard](https://admin.greengoods.app). More on which app to use in the [FAQ](/reference/faq#general).

## Good operating rhythm

1. Create the garden and confirm its domains and eligible actions before inviting a wider group.
2. Make an assessment early so stewards have clear context for later reviews.
3. Approve or reject submissions with feedback that maps back to the action and assessment.
4. Mint an impact certificate only after the evidence chain is strong enough to defend.
