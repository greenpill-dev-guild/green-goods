## Usage and source

Use SVG for scalable artwork and editable templates; PNG is ready to place. Keep logo proportions
and leave space around the artwork. See [Credits](/reference/credits#brand-assets) for usage guidance.
Application and docs design guides continue to own UI styling.

**Kit v3 · 4 October 2026.** Original artwork comes from the
[Green Goods branding board](https://www.figma.com/design/v4nQIhK4MPgWHKs8K8BpfI/Branding).
Graphics and templates are new kit compositions. The complete ZIP retains all colors, framing,
sizes, original vectors, and the font license. Download the
<a href="/brand/v3/export-manifest.json" download>asset manifest</a> or
<a href="/brand/v3/validation.json" download>validation record</a> for file details.

**Open questions:** measured clear space and minimum sizes, horizontal and wordmark-only logos,
photography and voice guidance, CMYK print files, approval of secondary colors, and formal brand
ownership and usage terms. The fresh Figma inventory remains pending access to the board.
