# Shared Library

Shared is the public application library for domain types, hooks, providers, stores, data modules,
workflows, i18n, and reusable UI foundations.

## Boundary

- Public entrypoints are the exports in `packages/shared/package.json`.
- Hooks are implemented here and consumed by client, admin, or agent through those exports.
- Modules isolate protocol and provider behavior from presentation packages.
- Storybook documents and tests shared UI foundations.
- The ontology sidecar owns cross-package vocabulary and lifecycle semantics.

Do not import `@green-goods/shared/src/**` from consumers. Read `packages/shared/AGENTS.md` and
`src/MODULES.md` before adding a module or public export. Use the generated [API index](./api-index)
for the current export inventory.
