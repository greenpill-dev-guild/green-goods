# Contracts Package

Contracts own Green Goods protocol state, roles, resolver enforcement, integration modules, and
checked-in deployment evidence.

## Navigation

- `src/tokens` and `src/accounts` define Garden identity and tokenbound ownership.
- `src/registries` define durable protocol registries.
- `src/resolvers` enforce EAS record rules.
- `src/modules` connect optional protocol capabilities.
- `script` owns deployment, upgrade, and release tooling.
- `deployments` records chain artifacts and its README owns the operator runbook.

Read `packages/contracts/AGENTS.md` before any change. Use Bun package scripts rather than raw Forge
commands. Deployment artifacts prove recorded addresses, not activation or live health; see the
generated [deployment status](../deployments/status).
