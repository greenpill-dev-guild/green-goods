# Ethereum Alignment

Green Goods uses Ethereum-compatible public infrastructure where shared verification matters, while
keeping private and recoverable interaction state off-chain.

## Design tests

- **Verifiability:** Work, approvals, assessments, roles, and deployments have inspectable
  authority sources.
- **User agency:** a participant can retain evidence and protocol records without depending on one
  interface vendor.
- **Least disclosure:** public records contain only what coordination requires; secrets,
  identities, and private QA evidence stay outside public artifacts.
- **Open implementation:** protocol and client behavior can be inspected, tested, and replaced.
- **Operational honesty:** a deployed address is not presented as an active or healthy feature
  without separate evidence.

These principles guide tradeoffs; resolvers and modules own the enforceable rules. Product language
belongs in the community [why we build](/community/why-we-build) and [how it
works](/community/how-it-works) pages.
