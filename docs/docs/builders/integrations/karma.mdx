# Karma GAP

[Karma GAP](https://gap.karmahq.xyz) (the Grantee Accountability Protocol) connects garden
activity to project reporting and milestone records. When the module is active, a garden's
assessment mirrors to a GAP milestone, so grant programs that already track accountability
through GAP see Green Goods work in the format they trust.

| Layer | Source |
|---|---|
| Module | `packages/contracts/src/modules/Karma.sol` |
