# Gardens

The Gardens module connects a Green Goods garden to
[Gardens](https://gardens.fund), the conviction-voting platform for community governance. Through
it, a garden's community can participate in signal pools: expressing sustained preference over
where support should flow, rather than one-off votes.

## Where it lives in the code

| Layer | Source |
|---|---|
| Module | `packages/contracts/src/modules/Gardens.sol` |
| Data access | `packages/shared/src/modules/data/gardens.ts` |
| Conviction hooks | `packages/shared/src/hooks/conviction` |

## Working with it locally

The [full-stack path](../getting-started#path-b-run-the-full-local-stack) forks Arbitrum One, so
recorded module state is available locally; live signal-pool behavior on the Gardens platform
itself needs the real chain.
