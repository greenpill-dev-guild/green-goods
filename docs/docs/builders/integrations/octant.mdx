# Octant

[Octant](https://docs.octant.app) provides the vault mechanics that let a garden hold an
endowment. Funders deposit into a garden vault and keep a claim on what they put in, while the
yield it earns flows to the garden's work. The deposit sits in a yield strategy, so like any
on-chain investment, a strategy loss or a contract bug could reduce what can be withdrawn. The Octant module owns vault creation, deposits, withdrawals,
and that yield-donation routing.

## Working with it locally

The [fork mode](../getting-started#other-modes) (`bun run dev -- fork`) runs a local fork of
Arbitrum One with the deployed vault contracts present, so deposit and withdrawal flows run
locally without real funds.
