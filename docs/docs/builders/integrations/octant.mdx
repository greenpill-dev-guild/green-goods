# Octant

[Octant](https://docs.octant.app) provides the vault mechanics that let a garden hold an
endowment: funders deposit into a garden vault, the principal stays theirs to withdraw, and the
yield flows to the garden's work. The Octant module owns vault creation, deposits, withdrawals,
and that yield-donation routing.

## Where it lives in the code

| Layer | Source |
|---|---|
| Module | `packages/contracts/src/modules/Octant.sol` |
| Vault data access | `packages/shared/src/modules/data/vaults.ts` and `vault-repository.ts` |
| Yield routing | `packages/shared/src/modules/data/yield-allocations.ts` |

The funder-facing behavior lives in the community docs'
[funder guide](/community/funder-guide); these sources are the machinery under it.

## Working with it locally

The [full-stack path](../getting-started#path-b-run-the-full-local-stack) forks Arbitrum One with
the deployed vault contracts present, so deposit and withdrawal flows run locally without real
funds.
