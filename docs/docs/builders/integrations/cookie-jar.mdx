# Cookie Jar

Cookie Jars are Green Goods' own distribution primitive: a garden-linked jar that lets a
community hand out small, capped allowances without a proposal process for every withdrawal.
Where vaults hold an endowment, a jar holds spending money; it's the difference between a
treasury and a kitchen tin everyone trusts each other to dip into.

## Where it lives in the code

| Layer | Source |
|---|---|
| Module and factory | `packages/contracts/src/modules/CookieJar.sol` |
| Data access | `packages/shared/src/modules/data/campaign-cookie-jars.ts` |
| Hooks | `packages/shared/src/hooks/cookie-jar` |

Unlike the other integrations, this one is native: there is no external protocol to link, and the
contract source above is the whole story.

## Working with it locally

The [full-stack path](../getting-started#path-b-run-the-full-local-stack) forks Arbitrum One with
the factory and module present, so jar creation and claim flows run locally without real funds.
