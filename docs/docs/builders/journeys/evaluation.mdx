# Evaluation Journey

**Goal:** create and inspect an Assessment without confusing evaluation with Work approval.

## Prerequisites

- The evaluator or Steward has the required Garden role.
- The selected chain has the required Assessment schema and resolver.
- Assessment content and supporting material are ready for durable storage.

## Flow

1. Open the Garden assessment surface in the admin Hub.
2. Enter the evaluation context and supporting content.
3. The shared assessment workflow prepares content and submits the EAS attestation.
4. The Garden assessment panel reads the resulting record for review.

Evaluators strengthen Assessment records; Stewards own Work approval decisions. If submission fails,
preserve the entered content, distinguish validation from provider failure, and retry only after
confirming chain and signer context.
