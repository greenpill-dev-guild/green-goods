# Funding Journey

**Goal:** help a funder choose a Garden funding path and verify the resulting position.

## Prerequisites

- A supported chain, connected wallet, and funded asset.
- A recorded Garden Vault or Cookie Jar for the selected network.
- Clear transaction copy covering approvals, amount, recipient, and recovery.

## Flow

1. Discover a Garden from the public funding surface.
2. Choose the available funding primitive and enter an amount.
3. Review wallet and transaction state before signing.
4. Submit through the shared Vault or Cookie Jar hook.
5. Confirm the indexed or chain-derived position before presenting completion.

If indexing lags, distinguish a submitted transaction from a confirmed read model. Never resubmit
blindly. Use the generated [Cookie Jar](../integrations/cookie-jar),
[Octant](../integrations/octant), and [deployment status](../deployments/status) pages for recorded
availability.
