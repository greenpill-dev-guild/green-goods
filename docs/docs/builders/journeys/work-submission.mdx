# Work Submission Journey

**Goal:** capture evidence locally, submit a Work attestation, and support a separate Steward review.

## Prerequisites

- The participant is authenticated and has a Garden context.
- The Action is available for that Garden.
- Media and notes meet client validation and privacy expectations.

## Flow

1. Select an Action and capture evidence.
2. Save recoverable local state before network work begins.
3. Upload media and submit the Work attestation through the shared mutation and job queue.
4. Show pending protocol state only after the attestation is recorded.
5. A Steward reviews the Work in admin and records a separate approval or rejection attestation.

Offline and failed submissions remain retryable local jobs. Retries must be idempotent and must not
turn UI queue state into a false protocol claim. Use the generated [state
diagrams](../architecture/sequence-diagrams) for current transitions.
