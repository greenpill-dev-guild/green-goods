# Getting Started

## First run

1. Clone the repository and run `npm run setup` only if Bun is not installed yet.
2. Configure the root environment through [Environment Management](./env-management).
3. Run `bun run setup:doctor` to check the local toolchain.
4. Read `AGENTS.md`, then the nearest package `AGENTS.md` for the surface you will change.
5. Start only the surface you need using the scripts documented in `scripts/README.md`.

## Find the owner

| Goal | Start here |
|---|---|
| Protocol or deployment behavior | `packages/contracts` |
| Shared hooks, modules, providers, or UI foundations | `packages/shared` |
| Public website or installed PWA | `packages/client` |
| Steward cockpit | `packages/admin` |
| Bot, webhook, or public Agent API | `packages/agent` |
| Event-derived read models | `packages/indexer` |

Use the generated [API index](./packages/api-index), [persona surfaces](./journeys/persona-surfaces),
and [deployment status](./deployments/status) for volatile inventories.

## Validate

Run `bun run validation:plan -- --intent <your change>` before selecting tests. Start with the
targeted proof it returns, then escalate only when a public contract, shared dependency, or critical
surface requires it.
