## Findings

1. **A second memo with the same title.** Phase 4 asks a same-date rerun to update the existing
   memo, which the Drive connector cannot do, so the run created a second
   `2026-10-18 research synthesis`. Continuity still works (newest four by title), but the title
   should carry a suffix for a same-date rerun, for example `(rerun)`, so the two cannot be confused.
2. **Recovered lines went into the sharer's message, not the closing message.** The spec places
   recovered lines in the closing message; the run merged them into the only sharer's message to keep
   one message and one mention per person, which the same section prefers. The spec should say:
   recovered lines for a sharer who has a message this run merge into it; otherwise the closing
   message.
3. **The water-cycle cluster became nine ❔ lines.** The morning run parked a candidate question
   from the "Rehydrating Australia" share and named the cluster beside it; this run asked for a why
   on each of the nine cluster links instead of filing them under that parked question. The spec's
   table allows it (organisation sites, a newsletter, a product page), and the ask reached the
   sharer in one line, but a share that matches a parked candidate question could be filed 🌱
   against it. One for the 29 October review rather than a spec change now.
4. **Count correction.** The run recounted the pending document at 19 proposed edits; the
   2026-10-18 first-run report said 20.
5. **The system row for a thread on an old digest** is expected and only appears in the rerun case.
