# Sharing acceptance cases

| Case | Observable completion evidence |
|---|---|
| Public consent | Unaccepted fields/media and stale source consent cannot appear in the snapshot |
| Evidence meaning | Missing, target, observed and interpreted values remain distinct; Work is counted once |
| Preview parity | Public HTML and crawler metadata use the same approved version and permitted assets |
| Corrections | Later source corrections label stale snapshots and invalidate/update caches under the accepted policy |
| Share outcomes | Native/composer/copy/download/cancel paths report their real outcome, never an inferred post |
| Platform limits | Unsupported file/target combinations have a usable fallback; no invented Facebook endpoint |
| Report provenance | Period, coverage, units, methods, source versions, uncertainty and correction labels survive exports |
| Accessible export | HTML/text/PDF and image alternative text pass the selected format/accessibility proof |
| Export recovery | Partial/failed renders can resume without producing mismatched artifact versions |
| Independence | No Certified or provider-grant dependency is introduced into public sharing |

H1/H2 require real conformance/policy evidence. Runtime cases are planned, not reported as run.
